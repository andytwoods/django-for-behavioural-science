# Where to go next

**Last checked: 25 August 2026.**

## Official documentation and tutorials

- [Django documentation](https://docs.djangoproject.com/en/stable/) is the reference
  for everything the framework does. Dense in places, but it's accurate, and it's what
  you check when an answer from anywhere else doesn't work.
- [The official Django tutorial](https://docs.djangoproject.com/en/stable/intro/tutorial01/)
  builds a polling app step by step. Start here if you already program a little and want
  Django's own account of itself.
- [Django Girls](https://djangogirls.org/) is a free beginner course, run in person
  by volunteers in a lot of places and also available to
  [work through online](https://tutorial.djangogirls.org/). It's the one I'd suggest if
  you're new to programming and would rather have people in the room.

## Books

- [Two Scoops of Django](https://feldroy.com/two-scoops-of-django) (Greenfeld &
  Greenfeld) is a book of conventions and pitfalls, not a tutorial. Read it once you've
  built something and want to know whether you built it the usual way. The current
  edition is written against Django 3.x, so some specifics have moved on, though most of
  the advice hasn't.
- [Django for Beginners](https://djangoforbeginners.com/) (Vincent) works through a
  series of small projects and takes each one as far as deployment. A sensible next
  course after this one.
- [Tango with Django](https://www.tangowithdjango.com/) (Azzopardi & Maxwell) is free
  to read online and aimed at students, building a single site from start to finish.

## Blogs

- [Simple is Better Than Complex](https://simpleisbetterthancomplex.com/) (Vitor
  Freitas) has long worked examples of the things everyone hits: forms, users, file
  uploads, many-to-many relations.
- [Real Python](https://realpython.com/) covers Python and Django at every level,
  some free and some behind a subscription.
- [adamj.eu](https://adamj.eu/) (Adam Johnson) is short posts on Django internals,
  performance and tooling from a Django contributor. For when you know Django and want to
  know it properly.

## Podcasts

- [Django Chat](https://djangochat.com/) interviews the people who build Django. Good
  for understanding why the framework is the shape it is.
- [Talk Python To Me](https://talkpython.fm/) is wider Python, one long interview a
  week.
- [Python Bytes](https://pythonbytes.fm/) is a short weekly round-up of Python news
  and new packages.

## Forums, news and Q&A

- [Django Forum](https://forum.djangoproject.com/) is the official one. Beginner
  questions are welcome and core developers read it.
- [Django News](https://django-news.com/) is a weekly newsletter of releases,
  articles and jobs. The cheapest way to keep up.
- [Stack Overflow](https://stackoverflow.com/questions/tagged/django) holds an
  enormous archive of Django questions. Search it before you post to it.

!!! tip "On asking an AI instead"
    Search engines, LLMs and coding agents answer most routine Django questions in
    seconds, and I use them constantly. The catch is version drift. Much of what they
    learned from was written for an older Django, and you'll be handed it with complete
    confidence. If an answer surprises you, or uses something you haven't seen in this
    tutorial, check it against the current documentation before building on it.

## Community, mentoring and events

- [Djangonaut Space](https://djangonaut.space/) is free, eight-week group mentoring
  that walks you into contributing to Django itself, backed by the Django Software
  Foundation. It ran its first session in January 2024 and reached its sixth in 2026.
  Apply once you're comfortable with Django and want to work on it alongside other
  people.
- [DjangoCon US](https://djangocon.us/) and
  [DjangoCon Europe](https://djangocon.eu/) are the annual conferences, with talks
  posted online afterwards. The sprint days are the easy way in: you sit down with
  maintainers and fix something small.
- Local Django and Python meetups. The
  [Django community page](https://www.djangoproject.com/community/) lists local groups
  and events. A room of people who've already hit your bug is worth a lot.
- Hackathons give you a weekend and a deadline. Useful for getting past the stage
  where you can follow a tutorial but freeze in front of an empty project.
- [PythonistaCafe](https://www.pythonistacafe.com/) is a paid, application-based
  community for Python developers. Worth a look if you want somewhere quieter than the
  public forums.

## Third-party packages

The package table in the article is a snapshot, and so is any list like it. Two places to
look instead:

- [Essential Django third-party packages](https://learndjango.com/tutorials/essential-django-3rd-party-packages)
  is a maintained shortlist of what most projects end up installing.
- [Django Packages](https://djangopackages.org/) is a directory that groups packages
  by the job they do and shows how actively each is maintained. Use it to compare
  options, and check the date of the last release before you commit to one.
