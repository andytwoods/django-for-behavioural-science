# Where to go next

**Last checked: 5 September 2026.**

## Official documentation and tutorials

- [Django documentation](https://docs.djangoproject.com/en/stable/) is the reference for the framework.
- [The official Django tutorial](https://docs.djangoproject.com/en/stable/intro/tutorial01/) builds a polling app step by step. Start here if you already code a little.
- [Django Girls](https://djangogirls.org/) provides a free beginner-friendly course, taught at volunteer-run workshops around the world and also available to [work through online](https://tutorial.djangogirls.org/). It's the one I'd suggest if you're new to coding.

## Books

- [Two Scoops of Django](https://feldroy.com/) (Greenfeld & Greenfeld) is a well-regarded book of Django best practices. The current edition covers Django 3.x, but much of the advice remains spot on.
- [Django for Beginners](https://djangoforbeginners.com/) (Vincent) works through a series of small projects and takes them as far as deployment. The current version covers Django 5.
- [Tango with Django](https://www.tangowithdjango.com/) (Azzopardi & Maxwell) is aimed at students and builds a single site from start to finish. Note that the freely available older editions cover older versions of Django; the newer Tango with Django 4 edition is available separately.

## Blogs

- [Simple is Better Than Complex](https://simpleisbetterthancomplex.com/) (Vitor Freitas) has clear examples covering topics such as forms, users, file uploads and many-to-many relationships.
- [Real Python](https://realpython.com/) covers all levels of Python and Django. Some material free and some behind a subscription.
- [adamj.eu](https://adamj.eu/) (Adam Johnson) covers Django internals, performance, testing and tooling, often in considerable (awesome) technical depth.

## Podcasts

- [Django Chat](https://djangochat.com/) interviews people prominent in the Django community. It's good for understanding both how Django is used and why the framework has developed the way it has.
- [Talk Python To Me](https://talkpython.fm/) covers Python more broadly through long-form interviews.
- [Python Bytes](https://pythonbytes.fm/) is a short regular round-up of Python news (my go to).

## Forums, news and Q&A

- [Django Forum](https://forum.djangoproject.com/) is the official discussion forum.
- [Django News](https://django-news.com/) publishes Django news and maintains a weekly newsletter covering releases, articles, projects and community news.

## Community, mentoring and events

- [Djangonaut Space](https://djangonaut.space/) is a free, eight-week group mentoring programme for people who want to become more involved in contributing to Django and related projects.
- [DjangoCon US](https://djangocon.us/) and [DjangoCon Europe](https://djangocon.eu/) are major annual Django conferences. Talks from previous conferences are available online.
- Local Django and Python meetups. The [Django community page](https://www.djangoproject.com/community/) is useful for finding groups and events.
- Hackathons and contribution sprints are another good way to meet other developers and work on real projects.
- [PythonistaCafe](https://www.pythonistacafe.com/) is a paid, online community for developing Python developers.

## Third-party packages

- [Essential Django third-party packages](https://learndjango.com/tutorials/essential-django-3rd-party-packages) is a useful shortlist of commonly used packages.
- [Django Packages](https://djangopackages.org/) is a directory that groups packages by job and provides information that can help you judge which projects are actively maintained (I love this site).
